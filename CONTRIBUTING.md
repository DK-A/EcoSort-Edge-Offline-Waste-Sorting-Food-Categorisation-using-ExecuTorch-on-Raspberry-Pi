# Contributing to EcoSort-Edge

Thank you for your interest in contributing to **EcoSort-Edge**, an open-source, air-gapped Edge AI civic waste sorting appliance developed for the **Namma AI Hackathon (Track 3: AI for Sustainability)**.

## How to Contribute

1. **Reporting Issues:**
   * If you encounter issues running the ExecuTorch runtime or evaluation pipeline, please open an Issue with your hardware platform details (e.g., Raspberry Pi 5 4GB/8GB, OS version, kernel).

2. **Benchmarking & Datasets:**
   * Contributions of regional Indian municipal waste imagery aligned with the **MoEFCC Solid Waste Management Rules 2026** are welcome.
   * Ensure any imagery contributed has no personal identifying information (PII) to comply with the **DPDP Act 2023**.

3. **Development Guidelines:**
   * All pull requests must pass the CI smoke tests.
   * Model export scripts should preserve INT8 quantization parity.
